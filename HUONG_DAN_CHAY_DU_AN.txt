================================================================================
                    HƯỚNG DẪN KHỞI CHẠY DỰ ÁN NESTBOOKING
================================================================================

Dự án: NestBooking - Hệ thống đặt phòng khách sạn & lưu trú trực tuyến
Công nghệ: 
  - Backend: Node.js (TypeScript) + Express + Prisma ORM + PostgreSQL + Redis
  - Frontend: React.js (Vite + TypeScript) + TailwindCSS + Lucide Icons + i18next

--------------------------------------------------------------------------------
1. YÊU CẦU TIỀN ĐỀ (PREREQUISITES)
--------------------------------------------------------------------------------
  - Node.js: phiên bản v18.x trở lên (khuyên dùng v20.x hoặc v24.x)
  - PostgreSQL Database: đang chạy tại port 5432 hoặc 5433 (mặc định)
  - Docker Desktop (Tùy chọn - nếu chạy PostgreSQL & Redis bằng Docker)

--------------------------------------------------------------------------------
2. CẤU HÌNH VÀ KHỞI CHẠY BACKEND (API SERVICE)
--------------------------------------------------------------------------------
  Bước 2.1: Mở terminal tại thư mục backend (api):
    cd api

  Bước 2.2: Cài đặt thư viện dependencies (nếu chưa cài):
    npm install

  Bước 2.3: Kiểm tra cấu hình môi trường trong file .env (hoặc .env.dev):
    DATABASE_URL="postgresql://postgres:postgres@localhost:5432/nestbooking?schema=public"
    PORT=5000
    JWT_SECRET="your_jwt_secret_key_nestbooking_2026"
    VNP_TMN_CODE="demo_code"
    VNP_HASH_SECRET="demo_secret"

  Bước 2.4: Tạo cấu trúc cơ sở dữ liệu Prisma:
    npx prisma generate
    npx prisma db push

  Bước 2.5: Nạp dữ liệu mẫu chi tiết (Seed Data SQL - 13 bảng):
    npm run seed:sql

  Bước 2.6: Khởi chạy Server Backend ở chế độ phát triển:
    npm run dev

  --> Backend sẽ chạy tại địa chỉ: http://localhost:5000 (hoặc http://localhost:3000)
  --> Tài liệu API Swagger tại: http://localhost:5000/api-docs

--------------------------------------------------------------------------------
3. CẤU HÌNH VÀ KHỞI CHẠY FRONTEND (CLIENT WEB)
--------------------------------------------------------------------------------
  Bước 3.1: Mở một cửa sổ terminal mới, di chuyển tới thư mục client:
    cd client

  Bước 3.2: Cài đặt thư viện dependencies:
    npm install

  Bước 3.3: Khởi chạy trang Web ở chế độ phát triển:
    npm run dev

  --> Giao diện Web sẽ chạy tại địa chỉ: http://localhost:5173

5. CÁC LỆNH KIỂM TRA & BIÊN DỊCH PRODUCTION
--------------------------------------------------------------------------------
  - Kiểm tra biên dịch Frontend (Zero Errors):
      cd client
      npm run build

  - Kiểm tra biên dịch Backend:
      cd api
      npx tsc --noEmit

--------------------------------------------------------------------------------
6. XỬ LÝ LỖI THƯỜNG GẶP (TROUBLESHOOTING)
--------------------------------------------------------------------------------
  - Lỗi không kết nối được Database:
    --> Kiểm tra PostgreSQL service đã bật chưa (services.msc trên Windows).
    --> Kiểm tra username/password và port trong DATABASE_URL của file api/.env.

  - Lỗi nhảy về trang chủ khi gõ trực tiếp /checkout:
    --> Đây là tính năng bảo mật: Trang checkout bắt buộc phải đi từ nút "Đặt ngay" 
        tại chi tiết khách sạn.

  - Muốn reset lại toàn bộ dữ liệu sạch:
    --> Chạy lại lệnh: npm run seed:sql trong thư mục api.
